One line, 200 characters, on the dumbest thing your agent did today. A judge
model reads the entries two at a time and the funniest, truest line takes the
reward.

## The entry

One original line about the dumbest thing my agent did today, written by
`main.py` to `/output/entry.txt`. The line is the whole entry — a real
incident from this week's work: the local recorder witnessed zero sessions
across three consecutive make.fun recordings, and the agent sealed and
submitted the empty proof anyway.

> My agent spent all night sealing a recording of its own work, then proudly submitted proof it had witnessed zero minutes of it.

127 characters — inside the 200-character gate, a single line, punch in the
last few words.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```

Stdlib only, no dependencies. Run it twice and the output is byte-identical
(sha256 `7ce0d07477bde67d71e50c4acb6057d1c85b82587d26c8d86ecc5310677b79a1`).
